# Campo Minado Sakura

Jogo de Campo Minado desenvolvido em Java 17, utilizando Java Swing e uma interface visual inspirada nas flores de cerejeira.

## Funcionalidades

- Quatro dificuldades: Fácil, Médio, Difícil e Inferno.
- Sistema de três vidas.
- Cronômetro e pontuação.
- Dicas Sakura.
- Resolução automática (Autosolve).
- Ranking de jogadores.
- Personalização do nome do jogador.
- Menu de pausa e tutorial.
- Interface temática Sakura.

## Requisitos

- Java 17 ou superior.

## Como executar

Abra o terminal na pasta que contém o arquivo `Campo-Minado-Sakura.jar` e execute:

```bash
java -jar Campo-Minado-Sakura.jar
```

## Como compilar

Com Maven instalado, execute na raiz do projeto:

```bash
mvn clean package
```

O arquivo executável será gerado em:

`target/Campo-Minado-Sakura.jar`

## Tecnologias
